# Nivalis Nights (尼瓦利斯之夜) - 内置管理员控制台 Mod

一款为单机生活模拟游戏《Nivalis Nights》打造的沉浸式内置开发者管理员控制台。

---

## 🌟 核心功能

- **快捷键开启**：进入游戏存档后，随时按键盘 **F1** 或 **~** 键呼出/收起控制台。
- **智能暂停**：呼出控制台时，游戏世界画面与游戏时间**自动冻结暂停**，调试完毕收起控制台时自动恢复流速。
- **常用功能一键直达**：
  - 💵 **资金调整**：一键 +1,000 元 / +10,000 元
  - 🛋️ **全家具发放**：一键解锁并获取游戏内全部家具
  - 🍳 **全菜谱解锁**：一键掌握所有烹饪配方
  - 🐟 **全鱼类图鉴**：一键解锁全部钓鱼图鉴
  - 🚢 **解锁飞船**：一键解锁个人飞船
  - 🗺️ **全快速旅行**：一键点亮地图所有快速旅行点
  - ⏰ **时间与环境**：一键切换正午、作物光速成熟、食材永久防腐开关、时间冻结
- **独家箱庭传送**：
  - 自动识别玩家**已拥有的店铺/酒吧**，点击一键精准传送直达！
  - 支持**跨箱庭地图切图**：自动触发官方切图过场加载，告别卡死或掉入虚空。
  - 列出当前街区**可购置的新店铺**，方便快速看房跑图。

## 📥 下载安装

### 1. 下载一键安装包
前往 [Releases 页面](https://github.com/chongyyye/Nivalis-Admin-Mod/releases/latest) 下载 **Nivalis_Admin_Mod_v1.2.0.zip**。

### 2. 放入游戏目录（两步安装）
1. 在 Steam 游戏库中右键《Nivalis Nights》 -> 选择【管理】 -> 点击【浏览本地文件】打开游戏根目录。
2. 将压缩包解压，把里面的全部内容（BepInEx 文件夹、doorstop_config.ini、winhttp.dll）直接复制粘贴到游戏根目录中即可。
3. 启动游戏，按 **F1** 键即可打开控制台！

---

## 🗑️ 卸载方式
如果不想继续使用，直接删除游戏根目录下的 BepInEx 文件夹、doorstop_config.ini 和 winhttp.dll 即可，游戏 100% 恢复纯净原版，不影响任何存档。
